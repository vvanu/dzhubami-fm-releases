# ДЖУБАмИ FM — сборки

Здесь публикуются готовые версии музыкального плеера для Android и Windows. Исходники приложения находятся в отдельном закрытом репозитории.

[Скачать сборки и посмотреть изменения](https://github.com/vvanu/dzhubami-fm-releases/releases)

- **Android 8.0+**: скачайте APK и подтвердите установку или обновление в Android.
- **Windows 10 / 11, x64**: распакуйте ZIP целиком в отдельную папку и запустите «ДЖУБАмИ FM.exe».
- Начиная с версии **1.8.0**, в настройках есть кнопка проверки обновлений. Загрузка и установка выполняются после согласия пользователя.

У каждого выпуска есть `SHA256SUMS.txt`. На Android также проверяется подпись приложения. На Windows обновление сохраняет прежнюю папку программы для восстановления; настройки и избранное хранятся отдельно.

Для первого перехода с 1.7.0 и более ранних версий установите 1.8.0 вручную. Следующие обновления можно получать через настройки плеера.
